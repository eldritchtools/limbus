# Limbus Company Tools

A community-driven collection of tools, databases, planners, and other resources for **Limbus Company**.

**Live Site:** [https://limbus.eldritchtools.com](https://limbus.eldritchtools.com)

## About

This repository contains the source code for the Limbus Company Tools website.

The project aims to provide a comprehensive set of tools and resources for the Limbus Company community while remaining free to use. New features are added over time based on community feedback and ideas.

## Features

- Databases and reference pages
- Build and MD Plan sharing
- Trackers
- Calculators
- Planners
- Community ratings and other features
- Community polls
- Miscellaneous tools

## Tech Stack

- Next.js
- React
- Supabase
- Cloudflare (DNS/CDN)
- Cloudflare R2
- Netlify
